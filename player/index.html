Интеграция с голосовым движком

Движок присылает события визем — плеер сам смешивает их с эмоциями, морганием и взглядом.

// window.avatar — доступен на этой странице
avatar.say([{ t: 0.00, v: "sil" },
            { t: 0.08, v: "SS"  },
            { t: 0.16, v: "E"   }]);   // тайминг от TTS
avatar.setViseme("oh", 0.8);       // потоковый режим
avatar.setEmotion("empathy", 0.7);
avatar.lookAt();                    // смотреть в камеру
